# Entwicklungsleitfaden

[Die benötigte Software installieren](./install-guide.md)

[Einen GG-Workspace vorbereiten](./install-guide/install-gg-workspace-guide.md)

In den Workspace wechseln

```bash
cd ~/dev/ # workspace
```

Claude starten

```bash
claude
```

Die Entwicklung in Claude starten

```bash
/gg-ticket
```

Folgende Skills in Claude verwenden

```bash
/gg-commit
/gg-push
/gg-review
/gg-publish
/gg-cleanup
```

`/gg` listet die Skills des Workflows auf und sagt, welcher als Nächstes
kommt.
