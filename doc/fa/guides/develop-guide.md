# راهنمای توسعه

[نرم‌افزارهای لازم را نصب کنید](./install-guide.md)

[یک فضای کاری (workspace) برای GG آماده کنید](./install-guide/install-gg-workspace-guide.md)

به فضای کاری بروید

```bash
cd ~/dev/ # workspace
```

claude را اجرا کنید

```bash
claude
```

توسعه را در Claude شروع کنید

```bash
/gg-ticket
```

از مهارت‌های (skills) زیر در Claude استفاده کنید

```bash
/gg-commit
/gg-push
/gg-review
/gg-publish
/gg-cleanup
```

`/gg` مهارت‌های گردش کار (workflow) را فهرست می‌کند و می‌گوید کدام یک
بعدی است.
